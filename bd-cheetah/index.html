    Quadrupeds

    Cheetah

    Also known as Boston Dynamics Cheetah

    n., quadruped. Boston Dynamics, United States, 2012. Retired.

    Tethered hydraulic quadruped built for DARPA that set the land speed record for a legged robot on a laboratory treadmill.

    Measures and facts
    MakerBoston Dynamics
    CountryUnited States
    First shown2012
    StatusRetired
    Top speed12.6 m/s (45.4 km/h)
    ActuationHydraulic actuators with an actuated flexing spine
    PowerOff board hydraulic power unit through a tether
    AutonomyNone, gait commanded from off board computers
    Paceapprox. 12.8 m/s

    Cheetah ran on a treadmill with an articulated back that flexed with each stride, powered by an off board hydraulic supply. Boston Dynamics tuned its galloping gait for speed rather than autonomy, and in 2012 it reached 45.5 kilometres per hour, beating the previous legged robot record set in the 1980s. The programme fed directly into WildCat, an untethered petrol powered machine built to run free of the treadmill and boom.

    Of note

    • Reached 45.5 km/h in 2012, a record for a legged robot
    • Funded by the DARPA Maximum Mobility and Manipulation programme
