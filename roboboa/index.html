    Roboboa

    n., snake robot. WowWee.

    Robotic snake made by WowWee with four angled body sections that rotate against one another so it can coil up.

    Measures and facts
    MakerWowWee

    Of note

    • Moves in a straight line using a motorised tail roller and midsection casters
